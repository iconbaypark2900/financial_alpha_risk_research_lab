## What was learned

**A test that exercises a function does not check it.** finGuard shipped 23
passing tests over `kelly.py` and `drawdown.py`; checking those same modules
against Kelly (1956), Thorp (2006) and Martin & McCann found **thirteen
defects**, including a sign inversion that returned a full long in the asset
Kelly said to short. The same lesson is already recorded in `core.py`'s
provenance note, where every invariant test passed over a wrong formula. An
invariant constrains the shape of an answer, never its correctness.

**Documents in prominent places cause damage in proportion to how official they
look.** Four superseded specs sat unmarked in the repository root. They are
where `requirements.txt` got 26 unused pins — `neo4j` included, on the same page
as a README section citing PRD 04's strike of it — and where the task backlog
got the idea this project needed semantic retrieval. Fixing the backlog without
finding that source would have left it to regenerate.

**Guards must be checked for teeth, and checked in the environment they claim to
support.** `assert_causal` passed a factor that read the future, because the
warm-up left the compared head all-NaN. The minimal-install CI job failed on
first run against two tests written this session. Both were found by trying to
break the thing, not by reading it.

**Prose does not drift less than numbers.** `test_readme_is_true.py` recomputes
every figure on that page, and the README still claimed the simulator was "not
yet migrated" one commit after it was — and four documents said "twelve defects"
against a table of thirteen. The numeric guards cannot read English. The count
is now checked against its own table; the rest is not, and that limit is stated
in `docs/REQUIREMENTS.md` rather than papered over.
